# Hybrid source retrieval

The original MVP requires PostgreSQL full-text search plus pgvector. `RETRIEVAL_MODE=hybrid` enables Azure embeddings for asynchronous PDF indexing and query embedding. Staging/production require that mode; a missing extension/schema fails startup rather than silently substituting lexical retrieval.

Configure `AZURE_EMBEDDING_ENDPOINT` (HTTPS Azure OpenAI root), `AZURE_EMBEDDING_DEPLOYMENT`, `AZURE_EMBEDDING_MODEL` (`text-embedding-3-small` or `text-embedding-3-large`) and `AZURE_EMBEDDING_API_KEY` through the deployment secret reference. The adapter uses the [Azure OpenAI embeddings API](https://learn.microsoft.com/en-us/rest/api/aifoundry/azureopenai/embeddings), fixed 1536 dimensions, bounded batches and response bytes, and a 30-second timeout. Each input is limited to 6000 UTF-8 bytes; oversized extraction chunks fail explicitly and must be split before indexing.

The privileged migration installs the [pgvector extension](https://github.com/pgvector/pgvector) where available. Azure infrastructure allowlists VECTOR. Embeddings have forced tenant RLS and bind source hash, chunk text hash and provider/deployment/model configuration. Existing matching vectors are reused; withdrawn, obsolete-hash or incompatible vectors cannot enter prompts. Reciprocal-rank fusion combines lexical and cosine rankings with source-balanced selection. Exact scans suit the pilot; index/recall tuning requires measured corpus evidence.

Existing approved sources require backfill after the migration or a model/configuration change. With a protected runtime database credential, operational admission secret and the same approved embedding configuration, set `EMBEDDING_BACKFILL_CONFIRM_ORGANIZATION` to the exact organization, then run `node tools/backfill-knowledge-embeddings.mjs ORGANIZATION ASSET_VERSION [AFTER_CHUNK]`. Each invocation indexes at most 100 chunks, returns a continuation cursor and audits the source/configuration/count. Repeat until the cursor is null. Interrupted batches can be repeated; cached vectors avoid repeated provider calls. Each provider batch uses shared admission with a reviewed `EMBEDDING_MAX_RUN_COST_CENTS` bound. Keep this operator command outside request handling. The API fails with missing-index evidence until current source chunks are indexed.

Optional reviewed source-unit rates label estimates separately from billed amounts. API query embeddings pass through shared admission; indexing runs inside budgeted asset jobs. Source meters record provider attempts without source text or credentials. Actual Azure provider quality, held-out retrieval recall, latency and billed cost still require deployment evidence.

The [real-extension regression](../tools/check-hybrid-retrieval.mjs) uses a separate pinned local pgvector service on loopback port 54339 and controlled vectors. It verifies semantic ranking, persisted cache, current source hashes, configuration mismatch, withdrawal and tenant isolation. [Protocol checks](../tools/check-azure-embeddings.mjs) exercise controlled Azure transport. Neither is real-provider quality acceptance.
