## CI acceptance still required

The [technical release workflow](../.github/workflows/technical-validation.yml) performs frozen install, typecheck, substantive source lint, fresh build, named pure/auth/database/integration profiles, dependency and redacted secret scans, API/worker image builds, packaged-entrypoint syntax checks, SBOMs and image vulnerability scans. It retains profile/security evidence and image archives with checksums. The image syntax check does not establish hosted startup or real cloud operation.

No green remote workflow or current image/SBOM/security scan is fabricated. A clean-run failure must block promotion until fixed; findings are not automatically ignored. Native GitHub branch protection must require the headless and image jobs before merge/promotion, configured by a repository administrator.
