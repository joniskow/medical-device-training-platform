### Final managed-owner, retrieval and observability corrections

Independent review confirmed that FORCE RLS hid maintenance rows from SECURITY DEFINER functions owned by a non-superuser. The implementation now installs a dedicated NOLOGIN, non-superuser, non-bypass owner with narrowly scoped routing policies and function permissions. API and outbox callers cannot assume that role or call the internal cross-organization hold helper. Real PostgreSQL tests exercise non-superuser ownership, held-source exclusion, tenant isolation and context restoration.

Hybrid retrieval now records fused ranking separately from lexical support, preserves unknown and actual zero values, and carries the pinned retrieval configuration into persisted AI evidence. A semantic ranking score cannot falsely increase lexical matching-passage counts.

TC28 instrumentation now includes four operational workbooks, bounded database and broker queue sampling, provider and cost signals, database-pressure alerts and an independent readiness probe. Financial signals follow durable commits. Telemetry connection or sink failures cannot prevent domain maintenance. Source tests and compilation do not substitute for live KQL results or an alert received by the named responder.
